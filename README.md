# SLOShoppr

A simple, convenient, and easy-to-use grocery list web application.
Current features:
  -Unlimited lists per person, automatically saved
  -Able to share with other users
  -Able to expand recipe prompts by clicking the "recipe" button

## Set-up instructions

1) Clone the repository, alongside the backend: ([Backend](https://github.com/konradowc/shoppinglist-frontend-web/edit/main/README.md#backend)) (follow the separate instructions there)
2) npm install
3) npm run dev

## Backend

The backend can be found here: https://github.com/konradowc/shoppinglist-backend
